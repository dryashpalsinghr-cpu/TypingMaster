TypeGuru Pro - Phase 7 Build Status (v0.7.0)
=============================================
PHASE 7 = Original Typing Games (Letter Bubbles, Word Runner, Key Defender).
WHAT WAS DONE IN THIS ENVIRONMENT:
  - All Phase 7 source files authored (see MANIFEST.txt).
  - Games use their OWN IndexedDB database ("typeguru-games-db") for high scores,
    and feed real keystroke data into the Phase 6 analytics store.
WHAT WAS **NOT** RUN HERE (honest):
  - npm ci / npm install : NOT run (no network access in this sandbox).
  - npm run typecheck     : NOT run.
  - npm run build         : NOT run.
  - Windows installer/EXE  : NOT built.
  - Games were NOT launched or play-tested.
WHY: The build sandbox has no internet, so dependencies could not be installed
and the TypeScript/Vite toolchain could not run. Nothing was faked.
HONESTY NOTES:
  - All three games are original code with no assets, art, levels, or word lists
    copied from any commercial typing product. Word pools were written for this app.
  - High scores are real, saved per profile; no seeded or fake scores.
  - Games record real keystrokes into analytics, so Statistics keep improving.
APPLY ORDER: Apply Phase 4, then 5, then 6, then this Phase 7 update. The new
App.tsx references pages from all prior phases, and gamesService imports the
Phase 6 analytics service (recordKeystrokes).
HOW TO VERIFY / BUILD YOURSELF:
  1. npm ci
  2. npm run typecheck
  3. npm run build
  4. Windows EXE: push to GitHub, run the "Build Windows EXE" Action, download
     the TypeGuruPro-Windows artifact. (Unsigned build.)
